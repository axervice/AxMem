# AxMem 北极星(永久,不压缩)

状态:v1,2026-09-24,Jax 拍板。本文件是 AxMem 的初衷、护城河、商业模式与 North Star 的唯一权威记录;PMM 只放指向本文件的一行地址。改动须 Jax 批准。

## 为什么做

长期使用 Claude Code 之后反复撞到同一个问题:**agent 的注意力会偏移**。规则写在记忆文件里,agent 甚至读过,但到了真正调用工具的那一刻,规则不在它的注意力上,同一个错误反复犯。多写记忆解决不了这个问题;常驻上下文越大越糟,重要规则被埋住,每一轮都为整堆文字付 token。

AxMem 不做「仿生记忆」「反思引擎」「沉淀智慧」。它是实用派:**用机器在 agent 动手的那一刻把注意力抓回来,并且是现有方案里 token 花得最少的一种。**

## 护城河

- **教训是闸,不是笔记。** hook 在工具调用那一刻拒绝会重犯已记录错误的动作;agent 不需要记住规则,它过不去这道闸。
- **召回按动作精确触发,不按相似度。** 只在碰到对应文件路径/工具时推送对应的那一条教训。
- **每次推送有回执。** 台账记录推了什么、推给谁、由什么触发;错误重犯时能证明规则到底有没有送到 agent 面前,系统能指出自己失灵在哪。
- **守卫自证活着。** 金丝雀 + 指纹 + 名册;死掉的守卫比没有守卫更糟。
- **机器只数数不判断。** 能用脚本判定的绝不交给模型;判断类的错交给审查者。

别家比谁记得多,AxMem 比谁拦得住、谁花得少。

## 商业模式

open-core,同一套安装分两层:

- **免费层(公开仓 `axervice/AxMem`,Apache-2.0)**:完整可用——写入闸、触发召回 + 回执台账、金丝雀、提交前闸与 lint、隔离闸、生命周期、适配器、处处自测。免费层代码不包含付费层代码。
- **付费层(AxMem Pro,私仓)**:让闸拿证据自我改进——因果影子记忆、五维对照器与回放、融合检索与评分基线、拒绝台账的自动放宽与回放证明。付费用户通过私有渠道把已安装的 AxMem 升级为完整系统。

私仓 `AxMem-dev` 是唯一真源,免费层由导出流水线自动推到公开仓。
