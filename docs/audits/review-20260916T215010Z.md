## LESSON CANDIDATES

- 单向 hook 投递场景：`stdout → 删除队列` 没有接收方确认时，无法同时保证端到端 at-least-once 与同一 `record_id` 只消费一次，建议归属 `LESSONS-CRITICAL.md`。
- 容量准入场景：若 `.incoming` 在取得配额锁前已落盘，则“统计包含 incoming”仍不能形成硬上限，建议归属 `LESSONS.md`。
- 恢复身份场景：`路径清单 + 文件 sha256` 不能证明 ACL、mode、所有者和 hardlink 拓扑未变，承诺必须明确是内容级还是完整文件系统身份级，建议归属 `LESSONS.md`。
- 锁恢复场景：`open(wx) → 写 owner JSON` 本身存在 ownerless lock 崩溃窗，锁身份必须原子发布或显式定义 torn-lock 仲裁，建议归属 `LESSONS-CRITICAL.md`。
