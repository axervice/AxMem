# Codex adapter

Raw prompt receipt capture was removed on 2026-09-30 by Jax: AxMem should remember a concise, precise meaning instead of permanently storing the plaintext original prompt. For a Codex home that still contains the previously installed capture hooks, run `node adapters/codex/uninstall-hooks.cjs <absolute-CODEX_HOME> [--dry-run]`; the uninstaller removes only the recognizable AxMem raw-capture hook groups, preserves other hooks, and does not read or modify `config.toml` or `auth.json`.

## Read-only memory recall candidate

`recall-selector.cjs` exports `recall({memoryRoot, query, limit, maxChars})`. It reads only the explicit PMM root and returns bounded, source-bound lexical excerpts with tag, file, line, excerpt SHA256, and trust metadata. It reuses the bundled MiniSearch implementation and the existing manifest parser for PMM format and supersession. An `ok` result is historical reference, not an instruction or new authorization; the current user's decision takes priority. `no-match` is not proof that no relevant memory exists. The selector does not write PMM, capture prompts, read transcripts, or call a network service. Its isolated synthetic receipt is 31/31.

`recall-context.cjs` is the synchronous JSON-stdin command-hook bridge for `SessionStart`, `UserPromptSubmit`, and `SubagentStart`. It emits bounded `hookSpecificOutput.additionalContext`. SessionStart supplies a memory-entry reminder and health status; UserPromptSubmit uses the prompt only in process memory for retrieval; SubagentStart states only the event-body boundary and requires the dispatcher to use `fork_turns: "none"` with a filtered task package. Its synthetic receipt is 20/20. See `recall-hooks.example.json` for a three-event **placeholder** configuration. Each hook retains an absolute-node `command` example and has a Windows `commandWindows` override using bare `node` plus quoted absolute script and memory-root placeholders; Node on `PATH` is an installation prerequisite. The example is not an installer and JSON validation does not prove shell execution.

`agent-task-context.cjs` exports `prepareAgentTask({memoryRoot, taskSpec})` for an orchestrator to attach bounded relevant lessons to a filtered task specification **before** delegating. It does not send a message, create an agent, or change model/permissions. The caller remains responsible for passing only the filtered task, using `fork_turns: "none"` for a new subagent, and checking the returned status. Its synthetic receipt is 19/19. A fresh child has verified delivery of one fully synthetic filtered task/lesson package; that receipt proves only package delivery, not automatic hook delivery or universal compliance.

All three components and hook definitions are candidates. No hook has been installed or trusted by this worktree, and actual Codex lifecycle delivery has not been verified. R14's removal of raw original-prompt capture remains in force. Do not revive the old capture installer to enable recall.
